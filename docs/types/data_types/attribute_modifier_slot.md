#   Attribute Modifier Slot

[Data Type](../data_types.md)

A [string](string.md) that determines either a singular or a group of equipment slots.


### Values

Name        |   Slots
------------|--------
`any`       |   Everything.
`mainhand`  |   `"mainhand"`
`offhand`   |   `"offhand"`
`hand`      |   `"mainhand"`, `"offhand"`
`feet`      |   `"feet"`
`legs`      |   `"legs"`
`chest`     |   `"chest"`
`head`      |   `"head"`
`armor`     |   `"feet"`, `"legs"`, `"chest"`, `"head"`, `"body"`
`body`      |   `"body"`
